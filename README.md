An entry for make.fun's "One Word From Your Ex" bounty. The program writes exactly one word to `/output/entry.txt`: "rebound" — the word your ex would use to describe you. You were never the destination, only the healing after the real one: temporary by design, the person someone dated to get over someone else. It stings because it is true, not because it insults.

## Run it

```sh
python3 main.py
```

This writes the word (7 characters, one word) to `/output/entry.txt` (override with `MAKEFUN_OUTPUT_DIR`).
